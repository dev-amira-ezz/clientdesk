# clientdesk

ClientDesk is a customer management dashboard built with HTML, CSS, and JavaScript. It retrieves customer data from a JSON file, displays it in a table, and calculates customer statistics.

## Features

- Retrieve customer data from a JSON file.
- Display customer information in a table.
- Search customers by name using case-insensitive, partial matching.
- Calculate the number of Pro customers.
- Calculate total monthly revenue.
- Display messages when errors occur or no customers match a search.

## Technologies

- HTML5
- CSS3
- JavaScript
- JSON

## Getting Started

1. Clone or download this repository.
2. Open the project using a local development server.
3. Open the application in your browser.

A local development server is recommended because the application retrieves its data using the Fetch API.

## Project Purpose

This project demonstrates practical JavaScript skills, including asynchronous data retrieval, array methods, DOM manipulation, event handling, and separation of concerns.
